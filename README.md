This module aims to add an easy to use macro for creating Dual Class Items from any available classes, adapted from the Symon-provided macro included with PF2e Workbench.

Notable changes include:
- Rewrote class picker for AppV2
- Added flags to the class items generated containing the UUIDs of each base class
- Added a resync button that shows up on Class items generated by this module, to resync the dual-class item with the originals in the case of system updates
- Fixed Rule Element de-duplication checks, so you shouldn't have any Rule Elements trying to do the same thing
- Cleaned up old code from earlier Foundry versions
- Fixed primary class DC label, so it's just the first class rather than the dual-named class name
- Fixed bug that required certain classes be added first.
